# Integração administrativa do ativaPDV

## O que é
Conectar o site já hospedado em ativapdv.app para que ele possa ser acompanhado e administrado por aqui.
Sem acesso confirmado ao código ou ao banco atuais, a primeira fase prioriza uma integração segura e reversível.

## Para quem é
Para o responsável pelo ativaPDV que precisa gerenciar o sistema existente, com foco inicial na operação de vendas e produtos.

## Funcionalidades e experiência principais
- Acessar o site hospedado a partir daqui, sem recriar o sistema atual.
- Identificar quais formas de integração e administração o site atual permite.
- Centralizar o acesso às funções disponíveis de PDV/vendas e produtos.
- Preservar o site atual e evitar alterações destrutivas durante a integração.
- Indicar claramente quando uma função depende de acesso ao código, banco de dados ou painel administrativo atual.

## Fase 1: o que será construído agora
- Criar uma área de administração com entrada para o ativaPDV hospedado.
- Implementar a primeira integração possível com o site atual, usando os acessos e informações disponíveis.
- Priorizar o acesso aos fluxos de PDV/vendas e ao gerenciamento de produtos.
- Mapear e exibir os limites da integração caso ainda não exista acesso ao código, banco ou APIs do site.
- Deixar a estrutura preparada para aprofundar a integração quando os acessos técnicos forem confirmados.
